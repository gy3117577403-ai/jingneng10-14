## 二、关键发现

1. **国外报价软件强在"算"，弱在"管"**：Lantek / Radan / Countfire 都是几何或图纸驱动的成本计算工具，算得准，但没有审批流、没有协同、没有转订单——报价算完就导出，管的是"一张纸"。
2. **国内 ERP 强在"管"，弱在"算"**：简道云、畅捷通有审批有 BOM，但报价是通用表单，没有钣金/成套的行业算法（展开面积、损耗率、加工费分摊这些都要自己配）。
3. **成套+钣金两栖是空位**：纯钣金报价软件不管成套组装（元器件、母线、二次接线），纯电气估算软件不管钣金加工（激光/折弯/喷涂）。两边都做的厂，只能 Excel + 人工拼。
4. **Excel 导入是刚需**：所有被调研的厂，报价起点都是 Excel。谁让业务员换工具，谁就输——必须沿用原表算法、无缝接进来。

## 三、京能协同报价模块功能边界建议

### 做深（护城河，别家没有或做不好）

- **价格库**：材料/箱柜 BOM/加工费三层，调价留历史、报价单做快照（调价不追溯历史单据）——这是定价权。
- **BOM 成本联动**：箱柜→物料→加工费，改一个数全单实时重算。这是成套厂报价员每天在 Excel 里手工做的事。
- **沿用原表算法的 Excel 导入**：业务员原来的表直接导进来就能用，零学习成本。这是推广成败手。
- **报价审批 + 协同**：提交→技术审核→领导审批，评论 @ 提及。这是国外报价软件全缺、国内 ERP 要配半天才有的。
- **转订单**：报价一键转订单，推 ERP 进入生产。闭环。

### 不做（别跟巨头拼投入产出比）

- **几何驱动的 CAD 自动报价**：Lantek / Radan 烧了十几年才做出来，咱们一个小团队拼不过，也不解决当前痛点（痛点是协同和价格管理，不是算不准）。
- **排版套料**：SigmaNEST 的地盘，以后真需要可以对接，不自己造。
- **通用 ERP（进销存/财务/人事）**：公司已经有 ERP，咱们只做协同层，不重复造轮子。

### 后做（已在规划，按序排）

1. 图纸快速分解（CAD 扒图 → BOM）
2. 快速报价（基于价格库一键出价）
3. 移动端审批（领导手机点一下就能批）
